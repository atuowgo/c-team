# C-Team v2 设计规范

> 参考 helio.im 设计语言，基于 shadcn/ui + Tailwind CSS v4 实现

---

## 一、色彩系统

### 1.1 背景层级

| Token | 色值 | 用途 |
|-------|------|------|
| `--bg-base` | `#09090b` | 页面底层背景 |
| `--bg-surface` | `#111114` | 侧边栏、卡片、面板 |
| `--bg-elevated` | `#18181b` | 按钮、输入框、悬浮卡片 |
| `--bg-hover` | `#1f1f24` | Hover 状态 |
| `--bg-active` | `#27272a` | 选中/激活状态 |

### 1.2 品牌色

| Token | 色值 | 用途 |
|-------|------|------|
| `--accent` | `#ff6b4a` | 主按钮、激活态、链接 |
| `--accent-hover` | `#ff8a65` | 主按钮 Hover |
| `--accent-muted` | `rgba(255,107,74,0.12)` | 选中背景 |

> 设计理由：warm coral（暖珊瑚色）在深色背景下有极强辨识度，同时传递温暖、活力的品牌调性，区别于 Linear 的蓝色、Notion 的黑色。

### 1.3 语义色

| Token | 色值 | 用途 |
|-------|------|------|
| `--ai` | `#6366f1` (Indigo) | AI 相关标识、提及 |
| `--ai-muted` | `rgba(99,102,241,0.15)` | AI 标签背景 |
| `--success` | `#22c55e` | 在线状态、成功 |
| `--warning` | `#f59e0b` | 忙碌状态、警告 |
| `--danger` | `#ef4444` | 删除、紧急、错误 |

### 1.4 文本色

| Token | 色值 | 用途 |
|-------|------|------|
| `--text-primary` | `#fafafa` | 主文本 |
| `--text-secondary` | `#a1a1aa` | 次级文本 |
| `--text-muted` | `#71717a` | 辅助/禁用文本 |

### 1.5 边框色

| Token | 色值 | 用途 |
|-------|------|------|
| `--border-default` | `#27272a` | 输入框、卡片边框 |
| `--border-subtle` | `#1f1f24` | 面板分割线 |

## 二、字体

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| Heading | 16px | 600 | 页面标题 |
| Subheading | 14px | 600 | 面板标题、频道名 |
| Body | 13.5px | 400 | 消息正文 |
| Body Strong | 13.5px | 500-600 | 发送者名、导航项 |
| Caption | 12-12.5px | 500 | 按钮、标签 |
| Small | 11-11.5px | 400-500 | 辅助文本、时间戳 |
| Micro | 10-10.5px | 600 | Badge、标签 |

字体族：`Inter` → 系统默认 sans-serif 回退

## 三、圆角

| Token | 值 | 用途 |
|-------|-----|------|
| `--radius-sm` | 6px | 小按钮、标签 |
| `--radius-md` | 8px | 默认组件、消息气泡 |
| `--radius-lg` | 12px | 卡片、面板 |
| `--radius-xl` | 16px | 大容器 |

## 四、间距

- 侧边栏导航项：`padding: 8px 12px; margin: 1px 8px`
- 消息气泡间距：`gap: 2px`（紧凑，类 Slack）
- 频道列表项：`padding: 6px 12px`
- 看板列间距：`gap: 12px`
- 卡片内边距：`padding: 12px`

## 五、组件设计决策

### 5.1 头像系统
- 使用渐变背景 + 首字母，替代纯灰色圆圈
- AI 同事：紫色系渐变（Indigo）
- 用户本人：品牌色渐变（Coral）
- 圆角从 `rounded-full`（圆形）改为 `rounded-md`（8px 圆角）——参考 helio.im

### 5.2 AI 标识
- AI 同事名字旁显示 `AI` 徽章：`bg-indigo-500/15 text-indigo-400`
- 消息中 @提及 AI 用 indigo 高亮

### 5.3 状态指示
- 在线：绿色圆点 `#22c55e`
- 忙碌：黄色圆点 `#f59e0b`
- 空闲：灰色圆点
- 离线：空心圆
- 状态点定位在头像右下角

### 5.4 导航
- 左侧边栏顶部：导航区（频道/看板/设置）
- 导航项带 SVG 图标，激活态用品牌色背景
- 频道列表在导航下方，带 `#` 前缀

### 5.5 看板
- 列背景：`bg-surface` + 边框
- 工单卡片：`bg-elevated` + 边框，hover 时边框变亮
- 优先级标签：语义化颜色（低=灰、中=蓝、高=橙、紧急=红）
- 分派标签：紫色系，显示 AI 同事头像 + 名字

### 5.6 状态栏
- 高度 36px（从 28px 提升）
- 带绿色状态点
- 信息用分隔线分组

## 六、与当前 UI 的关键差异

| 维度 | 当前 | v2 | 改进 |
|------|------|-----|------|
| 色彩 | 全灰度（saturation=0%） | 品牌色 + 语义色系统 | 从无品牌感→有辨识度 |
| 图标 | Unicode/emoji 混用 | 统一 SVG 图标 | 专业感 |
| 头像 | 纯灰色圆圈 | 渐变背景 + 首字母 | 信息区分度 |
| AI 标识 | 无 | 紫色 "AI" 徽章 | 一眼区分人/AI |
| 状态 | 黑白 Badge | 彩色状态点 | 语义化 |
| 空状态 | 裸文字 | 带图标+引导文案 | 用户引导 |
| 按钮 | 最小 20px | 最小 28px | 可点击性 |
| 状态栏 | 28px 高 | 36px 高 | 呼吸感 |
| 字体 | 系统默认 | Inter | 精致度 |
| 圆角 | 统一 0.5rem | 分层圆角系统 | 视觉层次 |
